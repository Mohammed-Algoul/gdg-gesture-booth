# Hand Landmarker model

`hand_landmarker.task` (float16) — Google MediaPipe Hand Landmarker, Apache-2.0.

Source: https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task

If this file is ever missing, the app shows a clear error and keeps working with
manual capture (Space). To restore it, either:

- download the URL above and save it here as `models/hand_landmarker.task`, or
- run `npm install && npm run vendor -- --model`.
